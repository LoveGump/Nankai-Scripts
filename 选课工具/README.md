# 南开大学选课脚本

基于 Node.js 和 Playwright 的浏览器自动选课脚本，适用于南开大学教务系统。脚本打开 Google Chrome，由你手动完成统一身份认证，然后查找指定课程，在设定时间点击“选课”并处理确认弹窗。

支持按课程序号、课程详情中的 `lesson.id` 或课程名称查找，也支持只查找、不提交的试运行。

> **除 `--dry-run` 外，运行命令会真实执行选课。** 不传参数也会按默认配置执行，请先核对目标课程和时间。脚本无法保证选课成功，最终结果以教务系统为准。

## 1. 安装

### 环境要求

- **Node.js 20 或更高版本**，并包含 npm（依据当前 `package-lock.json` 中的依赖要求）。
- **Google Chrome**：脚本固定使用本机 Chrome，且会显示浏览器窗口。
- 能正常访问南开大学教务系统，并拥有可登录的选课账号。

安装好 Node.js 和 Chrome 后，在终端检查：

```bash
node -v
npm -v
```

下载项目后，在终端进入包含 `package.json` 的目录，安装依赖：

```bash
cd "/你的路径/选课"
npm ci
```

`npm ci` 使用项目附带的锁文件安装依赖。无需全局安装 Playwright；仅安装 Playwright 自带的 Chromium 不能替代本脚本需要的 Google Chrome。

## 2. 首次使用：先试运行

以下示例中的 `3300`、`123456` 和课程名称都需要替换成你自己的目标课程信息。

例如，按选课列表第一列的“课程序号”查找：

```bash
npm start -- --course-no 3300 --dry-run
```

1. 等待脚本打开 Chrome。
2. 如果出现统一身份认证页面，在浏览器中手动登录。
3. 脚本进入指定选课阶段，查询目标课程，并在终端打印匹配到的课程行。
4. 核对课程名称、教师、班级等信息，同时检查生成的 `course-match.png` 截图。

`--dry-run` 会立即查询，不等待预约时间，也不会点击选课或提交。只有当前页面存在可识别的选课按钮时，才能完成试运行；未开放选课时可能查找失败。

脚本会保留浏览器以便检查。完成后可关闭脚本打开的 Chrome，并在终端按 `Ctrl+C` 结束程序，再启动下一次任务。

## 3. 正式选课

### 定时执行

确认试运行结果后，用相同的课程参数，去掉 `--dry-run`，设置执行时间：

```bash
npm start -- --course-no 3300 --at "2026-10-13 13:00:00"
```

日期仅为格式示例，请替换为实际选课日期。时间按**运行电脑的本机时区**解释；若按北京时间选课，请确认系统时区为北京时间、系统时间准确。

提前启动并完成登录，保持电脑唤醒、网络连通、终端和脚本打开的 Chrome 持续运行。脚本会尝试提前查询课程，到点后执行点击；等待期间不要刷新或操作选课页面。

### 立即执行

```bash
npm start -- --course-no 3300 --now
```

`--now` 在登录和页面准备完成后立即执行，**会真实点击和提交选课**，不能与 `--at` 同时使用。

### 使用默认配置

```bash
npm start -- --dry-run
```

当前代码内置的默认值为：

| 项目 | 默认值 |
| --- | --- |
| 课程名称 | 互联网数据库开发 |
| `lesson.id` | `656504` |
| 选课阶段 | 专业课、通识选修课、国际学分课正选第一阶段 |
| 执行时间 | 本机时区的今天 `13:00:00` |

直接运行 `npm start` 会使用上述配置真实选课。若启动时已超过当天 13:00，会报“目标时间已经过了”，不会自动改为次日；请指定未来的 `--at` 时间，或使用 `--now`。

## 4. 如何指定课程

### 按课程序号

使用选课列表第一列显示的纯数字编号，保留可能存在的前导零：

```bash
npm start -- --course-no 3300 --dry-run
```

脚本优先按课程序号查询，真实点击前校验目标行第一列是否完全匹配。也可加课程名称作为额外校验：

```bash
npm start -- --course-no 3300 --course-name "目标课程名称" --dry-run
```

### 按 lesson.id

打开课程详情，找到链接中的 `lesson.id`。例如链接包含 `lesson.id=123456`，则使用：

```bash
npm start -- --lesson-id 123456 --dry-run
```

仅提供 ID 时，脚本会在登录后尝试从课程详情解析名称，再按名称查询；真实提交前仍会校验同一课程行中的详情链接 ID。若无法解析名称，可显式补充：

```bash
npm start -- --lesson-id 123456 --course-name "目标课程名称" --dry-run
```

**`--course-no` 和 `--lesson-id` 是不同编号，不能混用。** 换学期后应重新确认编号，不要直接沿用示例或旧学期配置。

### 按课程名称

```bash
npm start -- --course-name "目标课程名称" --dry-run
```

名称匹配会忽略空白和中英文圆括号，并采用包含匹配。同名课程或多个教学班可能匹配到不同课程行，因此需要选定具体教学班时，优先提供课程序号或 `lesson.id`。

只要传入任意一个课程参数，未显式提供的其他课程参数就会清空，不会继续套用默认课程的 ID 或名称。

## 5. 命令行参数

通过 npm 传递参数时，保留 `npm start` 后面的 `--`：

```bash
npm start -- --help
```

| 参数 | 含义 |
| --- | --- |
| `--course-no "3300"` | 选课列表第一列的课程序号，必须为纯数字 |
| `--lesson-id "123456"` | 课程详情链接中的 `lesson.id`，必须为纯数字 |
| `--course-name "课程名称"` | 用于搜索和课程行校验；提供课程序号时，名称用于额外校验 |
| `--at "YYYY-MM-DD HH:mm:ss"` | 指定本机时区的执行时间，默认今天 13:00 |
| `--now` | 登录并准备完成后立即执行，与 `--at` 互斥 |
| `--dry-run` | 立即查找按钮、保存诊断文件，不点击、不提交 |
| `--help` | 显示命令帮助并退出 |

## 6. 选课阶段与重试配置

高级配置位于 `select-course.mjs` 顶部的 `CONFIG`：

| 配置项 | 当前值 / 作用 |
| --- | --- |
| `profileName` | 目标选课阶段名称 |
| `courseName` / `lessonId` | 未传课程参数时使用的默认课程 |
| `retryIntervalMs` | 未找到按钮时每轮等待 1500 毫秒 |
| `retryForMs` | 查找与重试窗口为 30000 毫秒 |
| `rateLimitBackoffMs` | 触发页面限速后等待 2500 毫秒 |

脚本从选课入口页查找目标阶段，动态获取 `electionProfile.id`，不依赖配置中写死的 `2079`。找不到目标阶段时会报错停止。

当前阶段识别还使用了 `discoverElectionUrl()` 中的 `tokens` 关键词作为备用匹配。若要适配其他选课阶段，需要同时检查 `profileName` 和这些关键词；目前没有切换阶段的命令行参数。

普通查找通过页面“查询”更新列表；触发“请不要点击过快”等提示后会等待并刷新页面。30 秒是重试窗口，页面加载等操作可能使实际运行时间更长。识别到名额已满、时间冲突等拒绝提示时会报错停止，并非持续刷课程序。

## 7. 运行结果与文件

终端显示“已点击”或“已提交”只代表执行了相应操作。请在教务系统的已选课程列表中确认最终结果。

脚本在运行目录保存以下文件，重复运行可能覆盖同名文件：

| 文件 | 用途 |
| --- | --- |
| `.chrome-course-profile/` | 独立的 Chrome 用户目录，保存登录会话等浏览器数据 |
| `course-match.png` / `.html` | 试运行找到按钮时的页面 |
| `selection-result.png` | 正式运行完成点击流程后的截图 |
| `entry-discovery-error.png` / `.html` | 无法找到选课阶段时的页面 |
| `course-search-timeout.png` / `.html` | 查找目标课程超时时的页面 |
| `course-match-error.png` / `.html` | 真实提交前课程行校验失败时的页面 |
| `selection-error.png` / `.html` | 参数非法或识别到选课拒绝提示时的页面 |
| `selection-after-click.png` / `.html` | 点击后未识别到确认操作时的页面 |

脚本不要求在代码中填写密码。浏览器用户目录和诊断文件可能包含登录状态或个人信息，项目已通过 `.gitignore` 忽略这些文件，分享项目时也请勿一并打包。

## 8. 常见问题

- **提示找不到 `node` 或 `npm`**：检查 Node.js 是否安装，并重新打开终端后再试。
- **无法启动 Chrome / 找不到浏览器可执行文件**：确认本机安装了 Google Chrome；脚本使用的是 `channel: 'chrome'`。
- **浏览器用户目录被占用**：先结束上一次脚本及其 Chrome 窗口，不要同时从同一目录启动多个实例。
- **登录失效或需要切换账号**：关闭脚本及其 Chrome 后，删除项目内的 `.chrome-course-profile/`，下次运行重新登录。
- **找不到选课阶段**：检查账号是否有该阶段入口，以及阶段名称是否变化；查看 `entry-discovery-error` 诊断文件。
- **找不到课程按钮**：确认编号类型、课程名称、选课阶段和开放状态，查看 `course-search-timeout` 文件。页面结构变化也可能需要调整脚本。
- **课程行校验失败**：检查多个课程参数是否指向同一门课、同一教学班，查看 `course-match-error` 文件。
- **日志仍提示“等待 13:00”**：当前这句提示为固定文本；实际执行时间由 `--at` 或 `--now` 决定，以启动时打印的“执行时间”为准。
