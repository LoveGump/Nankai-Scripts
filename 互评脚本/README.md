# 南开互评填写助手

用于南开复学网站学生互评页面的油猴脚本。评分选择“好”，“好的方面”和“需要改进的方面”可在面板中自行填写，支持单人填表及从当前学生列表逐个提交。

当前版本：**1.2.0**。脚本已通过语法检查和学生队列测试，尚未在登录后的真实网站完成端到端验证；页面结构不匹配时可能需要进一步适配。

## 功能介绍

- 自动选择能够明确识别的“好”评分选项。
- 自定义两项评语，首次默认值均为 `good`，两项均不能为空或全为空格。
- 在当前浏览器保存评语，刷新页面后恢复。
- 单人模式只填写，核对后由你手动提交。
- 批量模式从当前列表提取学生互评链接，去重后依次打开、填写并点击提交按钮。
- 跳过可识别的已评价学生，以及当前标签页中已记录为成功或结果不明的提交。
- 表单识别不完整、加载异常或未识别到明确成功提示时暂停，并显示原因。

## 安装方式

### 1. 安装 Tampermonkey（油猴）

打开 [Tampermonkey 官网](https://www.tampermonkey.net/)，选择自己的浏览器，通过官网提供的扩展商店入口安装。安装后可将扩展固定到浏览器工具栏，方便打开管理面板。

如果扩展提示缺少用户脚本执行权限，请按照 [Tampermonkey 官方权限说明](https://www.tampermonkey.net/faq.php#Q209) 完成设置，再刷新网页。

### 2. 添加互评脚本

1. 用文本编辑器打开本项目的 `peer-assessment.user.js`，复制全部内容，包括开头的 `// ==UserScript==` 元信息。
2. 点击浏览器工具栏中的 Tampermonkey 图标，选择“添加新脚本”或“创建新脚本”（名称可能随界面语言不同）。
3. 删除编辑器中的默认内容，粘贴完整脚本。
4. 保存：Windows / Linux 使用 `Ctrl + S`，macOS 使用 `Command + S`，也可使用编辑器的保存菜单。
5. 在 Tampermonkey 管理面板确认“南开互评填写助手”已启用。

正常使用不需要安装 Python、Node.js，也不需要运行命令行。

### 3. 登录并打开互评页面

在安装了脚本的同一个浏览器中，打开 [学生互评列表](https://fuxue.nankai.edu.cn/student/stuassess/id/3113.html)，按网站要求手动完成认证，再返回互评列表。若面板没有立即出现，刷新页面。

脚本直接使用浏览器现有的登录状态，无需在代码中填写密码或复制 Cookie。登录页本身不会显示助手面板。

适用页面路径为：

```text
https://fuxue.nankai.edu.cn/student/stuassess/*
https://fuxue.nankai.edu.cn/student/otherstu/*
```

其中 `3113` 是当前示例互评任务编号；批量功能按所在列表地址识别任务编号。

## 使用方法

### 设置自己的评语

页面右下角会显示“互评填写助手”，包含两个输入框：

| 输入框 | 用途 |
| --- | --- |
| 好的方面 | 填入你希望写入网站“好的方面”的文字 |
| 需要改进的方面 | 填入你希望写入网站“需要改进的方面”的文字 |

直接修改输入框内容即可，输入时会自动保存。评语可以包含中文、英文和换行。若浏览器无法保存，面板会提示，本次仍可使用输入的内容。

### 单个学生填写

1. 从列表进入某位学生的互评详情页。
2. 在助手面板中填写两项评语。
3. 点击 **“按规则填写”**。
4. 核对网站中的评分、两项评语，以及面板显示的已填写数量；未识别的项目请手动补全。
5. 点击网站原有的提交按钮，完成该学生的评价。

此模式不会自动提交。若要为不同学生写不同评语，可逐个进入详情页后修改面板内容再填写。

### 从列表逐个提交

**点击批量按钮后，脚本会实际提交评价。本轮所有学生使用开始时的同一组评语。**

1. 返回学生互评列表页，等待列表加载完成。
2. 在助手面板中填写本轮使用的两项评语。
3. 点击 **“从当前列表逐个提交”**。
4. 页面左侧会出现当前处理学生的嵌入页面，右下角显示进度和确认成功人数。
5. 脚本逐个填写并点击提交按钮，识别到明确成功提示后继续下一位。
6. 本页处理结束后，核对网站列表中的评价状态。如果列表有分页，手动切换到下一页，再点击批量按钮。

批量运行期间，评语输入框会锁定，避免同一轮使用不同内容。处理结束、停止或异常退出后可以再次编辑。

批量功能只处理点击开始时当前页面已经加载的符合条件的学生链接，不会自动翻页，也不会主动加载尚未显示的学生名单。

### 停止和继续

点击 **“停止后续提交”** 可停止后续操作。正在加载页面或等待提交结果时，可能需要等待该步骤结束；已经发出的提交不会被撤回。

停止后可以修改评语，再次从列表启动。脚本会跳过当前标签页中已记录的学生，但结果不明的学生也会跳过，需要先在网站核对实际状态。

## 常见问题

| 现象或提示 | 处理方法 |
| --- | --- |
| 页面没有助手面板 | 确认已登录，地址属于上述互评路径，脚本与扩展均已启用，且扩展获准在该网站运行，然后刷新页面。用户脚本执行权限可参考上面的官方说明。 |
| 请先填写某项评语 | 两项评语都必须有内容，不能只输入空格。 |
| 请先返回学生互评列表页 | 批量提交只能从列表页启动，学生详情页使用“按规则填写”。 |
| 当前列表没有可处理的学生链接 | 确认列表已加载，检查是否已评价、已有提交记录或需要切换分页；网站如果使用不同的链接结构，也可能无法识别。 |
| 表单识别不完整／无法唯一识别提交按钮 | 当前学生尚未自动提交。查看左侧页面，手动完成，或提供页面截图以便适配。 |
| 页面加载超时／可能需要重新登录 | 检查网络和登录状态，恢复访问后再操作。 |
| 未检测到明确的提交成功提示 | 当前提交可能已经成功。先检查学生页面或列表状态；该学生会被记为结果不明，不会自动重试。确认未提交后可手动处理。 |
| 评语没有保存 | 浏览器存储可能不可用，按面板提示重新输入；更换浏览器或清理网站数据也会影响保存内容。 |

脚本只识别页面中可见的特定成功文本，例如“提交成功”“评价成功”。如果网站仅跳转回列表、使用其他提示或弹出原生确认框，可能需要手动处理或进一步适配；不能仅凭助手的计数判断网站最终记录。

## 数据保存与限制

- **评语**保存在该网站的 `localStorage` 中，在同一浏览器配置下可跨刷新使用；不按登录账号区分，切换账号后应检查内容。
- **批量提交记录**保存在 `sessionStorage` 中，按列表页面路径区分，主要用于当前标签页会话内的去重；不是服务器记录，也不能保证跨标签页、跨浏览器或新会话去重。
- 脚本不会额外将评语发送给第三方服务；批量提交会通过网站原有表单将评价发送到学校网站。
- 当前自动评分规则固定为“好”，面板只支持自定义两项文字评语。
- 页面结构变化、自定义表单控件、嵌入页面限制或不同的提交提示，都可能影响识别和批量处理。

## 更新或停用

更新时，在 Tampermonkey 管理面板打开已有脚本，用新版 `peer-assessment.user.js` 的完整内容替换并保存，再刷新互评页面。不要同时启用多份旧版和新版脚本。

停用时，在管理面板关闭“南开互评填写助手”，然后刷新页面。如果正在批量运行，先点击“停止后续提交”并等待停止。
